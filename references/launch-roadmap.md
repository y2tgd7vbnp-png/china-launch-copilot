# 独立开发者上线路线图（实战时间线）

> 沉淀自 Drop2Markdown 项目 2026-08 的实际上线过程，费用/耗时均为真实值

## 总览：合规事项优先级

```
代码可运行
  ├─ ① git 推私有仓库（时间线证据，当天可完成，¥0）★最优先
  ├─ ② 软著申请（2-4个月，¥0-300/件）——可与一切并行
  ├─ ③ 品牌保护：商标检索+申请（8-12个月，¥300/类）——名字定了就申
  ├─ ④ 分发渠道合规：
  │     ├─ 桌面 App：签名/公证（macOS $99/年 可选；Win 无强制）
  │     ├─ 浏览器插件：Edge（免费）→ Chrome（$5）上架
  │     └─ 网站：域名（¥30-75/年）+ 大陆托管 + ICP 备案（¥0，1-3周）
  └─ ⑤ ICP 通过后 30 日内公安备案（¥0，3-7天）
```

## 各事项办理顺序的依赖关系

- 软著、商标、插件上架：**互相独立**，尽早并行
- ICP 备案依赖：域名实名（1天）+ 托管部署
- 公安备案依赖：ICP 备案号
- Chrome 上架依赖：隐私政策 URL（可先挂 GitHub Pages）

## 一句话原则

> **能并行的不串行，能免费的不花钱，能当天办的不拖延**——所有事项里只有 git 推仓是「不做就再也补不回来」的（时间戳不可逆），其他都有补救路径。
