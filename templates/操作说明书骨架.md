# 操作说明书骨架（软著申请配套）

> 按 Drop2Markdown 已成稿的桌面版/Web 版说明书提炼，一套骨架适配所有软件形态

## 写作要求（审查视角）

- 页数：10-20 页为宜，图文并茂（每个主要功能至少 1 张截图）
- 结构：封面 → 概述 → 安装/运行 → 分功能操作 → 常见问题
- 截图必须来自**当前申请版本**，界面文字与功能描述一致
- 页眉：软件全称 + 版本号（与申请表严格一致）
- 文字风格：客观描述操作步骤，不写营销话术

## 骨架结构

```
1. 封面
   软件名称（全称，与申请表一致）
   版本号 V1.0
   著作权人：XXX

2. 软件概述
   2.1 软件简介（100-200 字：是什么、给谁用、解决什么问题）
   2.2 运行环境（操作系统/浏览器/依赖版本，如 Python 3.9+）
   2.3 软件结构（目录树或模块图，体现自主开发）

3. 安装与启动
   3.1 获取方式（安装包/解压即用）
   3.2 安装步骤（截图：解压、拖入应用程序、权限勾选）
   3.3 首次运行验证（截图：成功界面）

4. 功能操作（核心章节，按功能模块展开）
   每个功能统一三段式：
   4.X.1 功能说明（做什么）
   4.X.2 操作步骤（截图 1：入口 → 截图 2：过程 → 截图 3：结果）
   4.X.3 结果说明（输出物在哪、长什么样）

5. 常见问题与处理
   5.1 权限问题（如 macOS 文件和文件夹授权失败怎么办）
   5.2 兼容性问题（如 Windows 杀软误报的处理）
   5.3 其他（卸载、升级）

6. 版本信息
   当前版本号、开发完成日期
```

## 分形态适配要点

| 形态 | 侧重章节 | 特殊注意 |
|---|---|---|
| 桌面 App | 安装权限、拖放操作 | macOS TCC 授权截图、Windows 安全提示截图都放进去 |
| Web 版 | 无安装，直接功能操作 | 部署 URL 截图、浏览器兼容说明 |
| 浏览器插件 | 加载已解压扩展 | chrome://extensions 安装过程截图必须完整 |
| CLI/服务类 | 命令行示例 | 终端输出截图 + 典型参数表 |
