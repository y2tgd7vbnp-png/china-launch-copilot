# China Launch Copilot · 大陆上线合规助手

> 帮独立开发者把「代码写完了 → 合法上线运营」之间的所有合规事项一次跑通。
> 由资深法务用真实项目（Drop2Markdown：软著 3 件 + ICP 备案 + 公安备案 + 商标 + 插件上架全流程亲历）的实战经验沉淀而成。

## 为什么需要它

个人开发者上线一款产品，代码之外还有一整套合规动作：软件著作权、ICP 备案、公安备案、商标检索与注册、插件商店上架、隐私政策……每件事单独查都有一堆过时攻略，踩坑成本高。这个项目把一套**法务视角 + 工程实操**的完整路径模板化。

## 作为 WorkBuddy Skill 使用

将本仓库 clone 到 `~/.workbuddy/skills/`：

```bash
git clone git@github.com:y2tgd7vbnp-png/china-launch-copilot.git ~/.workbuddy/skills/china-launch-copilot
```

之后对 AI 说「我要申请软著」「ICP 备案怎么办理」即可触发。

## 作为对话知识库使用

不使用 WorkBuddy 的读者，直接阅读 `templates/` 与 `references/` 下的 Markdown，每份都是可独立照做的行动清单。

## 内容纪律

1. 所有流程/费用/耗时来自真实项目实践，标注出处
2. 涉及官方最新政策时先核实再落笔，附来源
3. 个人主体视角优先，企业主体场景单独标注
